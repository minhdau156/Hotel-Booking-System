Sổ tay Swing

Kiến thức Swing cốt lõi — tra cứu nhanh, không cần đọc tuần tự.

Nguồn Toàn bộ nội dung tổng hợp từ tài liệu chính thức của Oracle (liên kết đi kèm mỗi mục). Xem RESOURCES.md để có danh sách đầy đủ kèm ghi chú.

1. Luật nền tảng

  • Mọi thao tác với component Swing phải chạy trên Event Dispatch Thread (EDT). Component Swing không an toàn luồng (not thread-safe) — sửa chúng từ nhiều luồng cùng lúc gây lỗi khó tái hiện. Trong một chương trình Swing bình thường, code trong các listener (nút bấm, chọn dòng bảng...) đã chạy sẵn trên EDT; bạn chỉ cần chủ động nhảy vào EDT một lần duy nhất lúc khởi động, bằng SwingUtilities.invokeLater(...). (Oracle: The Event Dispatch Thread)
  • Việc chạy lâu (gọi mạng, gọi DB, tính toán nặng) không nên chạy trực tiếp trên EDT — nó sẽ làm UI "đơ" vì EDT bận xử lý việc đó thay vì vẽ lại màn hình. Với việc nhỏ/nhanh thì gọi thẳng trong listener vẫn ổn; việc thật sự nặng nên đưa ra luồng nền (ví dụ SwingWorker) rồi cập nhật UI trở lại qua invokeLater.
  • Mọi JTable phải được bọc trong JScrollPane. Thêm JTable trần vào panel sẽ không hiện cả dòng tiêu đề cột — lỗi phổ biến nhất khi mới học Swing.
  • Một màn hình thường là một lớp con của JPanel. Dựng các thành phần con trong constructor, sắp xếp bằng LayoutManager, và để lộ ra 1-2 phương thức public (ví dụ refresh()) để nơi khác gọi khi dữ liệu thay đổi.

2. JFrame và vòng đời cửa sổ

Nguồn: Oracle: Getting Started with Swing

SwingUtilities.invokeLater(() -> {
    JFrame frame = new JFrame("Tiêu đề");
    frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
    frame.setSize(1000, 700);
    frame.setLocationRelativeTo(null); // căn giữa màn hình
    frame.add(mainPanel);
    frame.setVisible(true); // luôn gọi cuối cùng
});
Phương thứcÝ nghĩa
setDefaultCloseOperationHành vi khi bấm nút X. EXIT_ON_CLOSE thoát cả ứng dụng; DISPOSE_ON_CLOSE chỉ đóng cửa sổ đó (dùng khi bạn có nhiều cửa sổ và tự quản lý vòng đời).
setSize(w, h)Kích thước cửa sổ theo pixel.
setLocationRelativeTo(null)Căn giữa màn hình. Gọi sau setSize.
setVisible(true)Luôn là dòng cuối cùng — trước đó cửa sổ chưa hiển thị dù bạn đã thêm component.

JDialog hoạt động tương tự JFrame nhưng luôn gắn với một cửa sổ cha, và thường được tạo gián tiếp qua JOptionPane (mục 6) thay vì tự tay dựng.

5. JTable + TableModel

Nguồn: Oracle: How to Use Tables · Oracle: AbstractTableModel API

JTable tự nó không chứa dữ liệu — nó chỉ vẽ những gì một TableModel cung cấp. Cách phổ biến nhất là viết một lớp con kế thừa AbstractTableModel, chỉ cần cài đặt 4 phương thức:

public class PersonTableModel extends AbstractTableModel {
    private List<Person> rows = new ArrayList<>();
    private final String[] columns = {"Tên", "Tuổi"};

    public void setRows(List<Person> rows) {
        this.rows = rows;
        fireTableDataChanged(); // QUÊN DÒNG NÀY = bảng không bao giờ cập nhật
    }

    @Override public int getRowCount() { return rows.size(); }
    @Override public int getColumnCount() { return columns.length; }
    @Override public String getColumnName(int col) { return columns[col]; }
    @Override public Object getValueAt(int row, int col) {
        Person p = rows.get(row);
        return col == 0 ? p.getName() : p.getAge();
    }
}
Lỗi thường gặp Quên fireTableDataChanged() sau khi thay dữ liệu → bảng đứng yên dù dữ liệu đã đổi. Quên bọc JScrollPane → mất luôn hàng tiêu đề cột.

Muốn biết dòng nào đang được chọn: int row = table.getSelectedRow(); rồi lấy phần tử tương ứng trong danh sách dữ liệu gốc.

7. JComboBox<T>

Nguồn: Oracle: How to Use Combo Boxes

JComboBox<String> combo = new JComboBox<>(new String[] {"Nhỏ", "Vừa", "Lớn"});
String selected = (String) combo.getSelectedItem();
combo.addActionListener(e -> System.out.println("Đã chọn: " + combo.getSelectedItem()));

Khi phần tử là một đối tượng tự định nghĩa (không phải String), dropdown mặc định sẽ hiện toString() của nó — hoặc ClassName@hashcode nếu bạn chưa override. Cách đơn giản nhất là override toString() để trả về tên hiển thị; nếu không muốn đụng vào lớp model, gắn combo.setRenderer(...) tuỳ chỉnh.

8. JSpinner

Nguồn: Oracle: How to Use Spinners

JSpinner nhận một SpinnerModel, phổ biến nhất là 3 loại:

ModelDùng cho
SpinnerNumberModel(value, min, max, step)Chọn số trong khoảng, có bước nhảy
SpinnerDateModel()Chọn ngày/giờ — Swing lõi không có lịch chọn ngày (date picker) riêng, đây là cách "gốc" gần nhất
SpinnerListModel(list)Chọn 1 trong danh sách cố định, cuộn qua lại bằng nút mũi tên
JSpinner dateSpinner = new JSpinner(new SpinnerDateModel());
dateSpinner.setEditor(new JSpinner.DateEditor(dateSpinner, "yyyy-MM-dd"));

// Đọc giá trị ra LocalDate:
Date raw = (Date) dateSpinner.getValue();
LocalDate date = raw.toInstant().atZone(ZoneId.systemDefault()).toLocalDate();

9. Điều hướng nhiều màn hình: CardLayout

Nguồn: Oracle: How to Use CardLayout

CardLayout cardLayout = new CardLayout();
JPanel content = new JPanel(cardLayout);

content.add(panelA, "A");
content.add(panelB, "B");

cardLayout.show(content, "A"); // gọi lại bất cứ lúc nào để đổi màn hình đang hiện

Đây là cách chuẩn để làm ứng dụng "nhiều màn hình trong một cửa sổ" mà không cần mở JFrame mới mỗi lần chuyển màn hình.

10. Lắng nghe sự kiện (Event Listener)

Nguồn: Oracle: How to Write an Action Listener · Oracle: General Information about Writing Event Listeners

Tình huốngInterfaceVí dụ
Bấm nút / chọn combo box / Enter trong ô nhậpActionListenerbtn.addActionListener(e -> doSomething())
Click chuột (kể cả double-click) trên một component bất kỳMouseListener (thường dùng lớp MouseAdapter để khỏi phải cài đặt hết các phương thức của interface)comp.addMouseListener(new MouseAdapter() { public void mouseClicked(MouseEvent e) { ... } })
Theo dõi dòng nào đang được chọn trong bảng/danh sáchListSelectionListenertable.getSelectionModel().addListSelectionListener(e -> ...)
Theo dõi nội dung ô nhập thay đổi theo từng ký tự gõDocumentListenergắn qua textField.getDocument().addDocumentListener(...)

Nguyên tắc chung: hầu hết listener interface trong Swing chỉ có 1-3 phương thức trừu tượng, và Java cho phép dùng lambda khi interface chỉ có đúng 1 phương thức (functional interface) — ActionListener là ví dụ điển hình, còn MouseListener có 5 phương thức nên thường dùng MouseAdapter (lớp có sẵn cài đặt rỗng cho tất cả) rồi chỉ override cái mình cần.

11. Checklist trước khi coi một màn hình là "xong"

  • Mọi JTable đã được bọc trong JScrollPane.
  • Mọi nút bấm đều có addActionListener gắn kèm.
  • Mọi thao tác đổi dữ liệu đều kết thúc bằng việc cập nhật lại UI (gọi lại fireTableDataChanged() hoặc refresh() tương đương).
  • Lỗi validate/exception được bắt và hiển thị cho người dùng qua dialog, không để lộ stack trace thô.
  • Nếu cần nhập ngày, cân nhắc JSpinner + SpinnerDateModel (mục 8) thay vì ô văn bản tự do dễ gõ sai định dạng.
