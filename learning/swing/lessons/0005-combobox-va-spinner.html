JComboBox và JSpinner

Thay ô nhập tự do bằng lựa chọn có kiểm soát — ít lỗi nhập liệu hơn hẳn so với JTextField.

Nguồn chính Đọc trước: Oracle — How to Use Combo Boxes, Oracle — How to Use Spinners.

1. JComboBox<T> — chọn 1 trong danh sách có sẵn

JComboBox<String> sizeCombo = new JComboBox<>(new String[] {"Nhỏ", "Vừa", "Lớn"});
String selected = (String) sizeCombo.getSelectedItem();
sizeCombo.addActionListener(e -> System.out.println("Chọn: " + sizeCombo.getSelectedItem()));

Combo box cũng hoạt động tốt với các đối tượng tự định nghĩa, không chỉ String:

JComboBox<Category> categoryCombo = new JComboBox<>(categories.toArray(new Category[0]));
Category selected = (Category) categoryCombo.getSelectedItem();
Lỗi hay gặp Nếu Category chưa override toString(), dropdown sẽ hiện những dòng khó đọc kiểu Category@6bc7c054 thay vì tên thật. Cách đơn giản nhất: override toString() trong lớp Category để trả về tên hiển thị. Không muốn đụng vào lớp model thì gắn combo.setRenderer(...) tuỳ chỉnh — phức tạp hơn nhưng tách biệt "hiển thị" khỏi "dữ liệu".

2. JSpinner — ba loại model

ModelDùng choVí dụ
SpinnerNumberModel(value, min, max, step)Số trong một khoảng, có bước nhảySố lượng, độ tuổi, tiền (kết hợp định dạng)
SpinnerDateModel()Ngày/giờNgày sinh, khoảng thời gian báo cáo
SpinnerListModel(list)Một danh sách cố định, cuộn qua lạiDanh sách trạng thái, danh sách size áo
// Số, từ 1 đến 100, bước nhảy 1, giá trị khởi đầu 1
JSpinner qtySpinner = new JSpinner(new SpinnerNumberModel(1, 1, 100, 1));

// Ngày — Swing lõi không có lịch chọn ngày (date picker) riêng, đây là cách "gốc" gần nhất
JSpinner dateSpinner = new JSpinner(new SpinnerDateModel());
dateSpinner.setEditor(new JSpinner.DateEditor(dateSpinner, "yyyy-MM-dd"));

3. Đọc giá trị ra kiểu bạn thực sự cần

int quantity = (Integer) qtySpinner.getValue();

Date raw = (Date) dateSpinner.getValue();
LocalDate date = raw.toInstant().atZone(ZoneId.systemDefault()).toLocalDate();

JSpinner.getValue() luôn trả về Object — bạn phải ép kiểu đúng theo loại model đang dùng (Integer cho SpinnerNumberModel, java.util.Date cho SpinnerDateModel). Vì phần lớn code Java hiện đại dùng java.time.LocalDate thay vì java.util.Date cũ, bước chuyển đổi ở trên gần như luôn cần thiết.

Kiểm tra nhanh

1. JComboBox chứa các object tự định nghĩa, chưa override toString(). Dropdown sẽ hiện gì?

Đúng — không override toString(), Java dùng cách hiển thị mặc định (tên lớp + mã hash), không đọc được.
Chưa đúng — Java không tự đoán trường nào để hiển thị; bạn phải tự override toString() hoặc gắn renderer.

2. SpinnerDateModel dùng để làm gì?

Đúng — đây là model dành riêng cho ngày/giờ, dùng kèm JSpinner.DateEditor để định dạng hiển thị.
Chưa đúng — mô tả đó khớp với SpinnerNumberModel hoặc SpinnerListModel, không phải SpinnerDateModel.

3. Vì sao nên dùng JSpinner + SpinnerDateModel để nhập ngày, thay vì một JTextField tự do?

Đúng — JSpinner ràng buộc định dạng và giới hạn giá trị hợp lệ ngay từ lúc nhập, không cần validate chuỗi thủ công sau đó.
Chưa đúng — cả hai component đều tồn tại và JTextField gõ số bình thường; vấn đề nằm ở việc kiểm soát định dạng, không phải tốc độ hay khả năng tồn tại.

Bài tập thực hành

  1. Dựng một form (dùng lại mẫu GridLayout từ Bài 2/4): một JComboBox<String> chọn "Nam"/"Nữ"/"Khác", một JSpinner dùng SpinnerNumberModel cho "Tuổi" (giới hạn 0-120), và một JSpinner dùng SpinnerDateModel cho "Ngày sinh".
  2. Thêm một nút "In thông tin" — khi bấm, đọc cả 3 giá trị ra đúng kiểu (String, int, LocalDate) và in ra console theo định dạng: Giới tính: X, Tuổi: Y, Ngày sinh: Z.
  3. Thử nhập tuổi vượt quá 120 bằng cách bấm mũi tên tăng liên tục — quan sát việc JSpinner tự chặn lại ở giá trị max, so với việc bạn phải tự viết code kiểm tra nếu dùng JTextField.
  4. Tự kiểm tra:
    • [ ] Giá trị tuổi không bao giờ vượt quá 120 hay xuống dưới 0, kể cả khi bấm mũi tên liên tục.
    • [ ] Giá trị ngày sinh in ra đúng là một LocalDate hợp lệ, không phải chuỗi thô hay Date chưa chuyển đổi.
  5. Áp dụng vào project của bạn: bất kỳ chỗ nào trong ứng dụng cần người dùng chọn một giá trị từ tập hữu hạn (loại, trạng thái, danh mục) hoặc nhập ngày/số có giới hạn hợp lý, ưu tiên JComboBox/JSpinner thay vì JTextField — nó loại bỏ hẳn một lớp lỗi nhập liệu mà bạn sẽ phải tự validate nếu dùng ô nhập tự do.
Đừng ngại hỏi Việc ép kiểu Object trả về từ getValue()/getSelectedItem() hay bị nhầm kiểu (ClassCastException) — nếu gặp lỗi này, dán stack trace ra để được chỉ đúng chỗ sai.
